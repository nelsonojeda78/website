# Sitio Web - Mi Casa Soluciones

## Descripción

Sitio web comercial responsivo para **Mi Casa Soluciones**, empresa de servicios integrales para el hogar en La Libertad y Salinas, Santa Elena, Ecuador.

## Características Principales

### Diseño Responsivo
- ✅ Compatible con PC, tablets y smartphones
- ✅ Menú hamburguesa para dispositivos móviles
- ✅ Adaptación automática de columnas y tamaños de fuente

### Identidad de Marca
- Colores oficiales: Ámbar (#FFB000), Carbón (#393536), Blanco (#FFFFFF)
- Tipografías: Montserrat (títulos) e Inter (cuerpo)
- Logo y emblema según manual de marca

### Secciones del Sitio

1. **Header/Navegación**
   - Logo de la empresa
   - Menú de navegación
   - Botón de WhatsApp para cotizar

2. **Hero Section con Video**
   - Placeholder para video explicativo
   - Mensaje emocional sobre frustración del cliente
   - Promesa de valor: "Una sola llamada, todo resuelto y por escrito"
   - Badges de confianza (garantía, presupuesto sin costo, precio cerrado)

3. **Sección "Sabemos lo que sientes"**

4. **Servicios (6 líneas de negocio)**
   - Mi Casa Agua (Gasfitería)
   - Mi Casa Luz (Electricidad)
   - Mi Casa Metal (Soldadura/Herrería)
   - Mi Casa Diseño (Remodelación)
   - Mi Casa Color (Pintura)

5. **Antes y Después**
   - Galería interactiva con slider
   - Imágenes de ejemplo (reemplazables con fotos reales)
   - Información de cada proyecto (precio, tiempo)

6. **Diferenciales**
   - 8 razones para elegirnos
   - Testimonio de cliente satisfecho
   - Enfoque en transparencia, garantía y puntualidad

7. **Call to Action Final**
   - Botones de WhatsApp y teléfono
   - Nota sobre visita y presupuesto gratis

8. **Footer**
   - Logo y descripción
   - Redes sociales (Facebook, Instagram)
   - Lista de servicios
   - Información de contacto
   - Badge de garantía de 12 meses

## Personalización

### Reemplazar Imágenes
Las imágenes actuales son placeholders de placehold.co. Para usar fotos reales:

1. Guardar las fotos en una carpeta `images/`
2. Actualizar las rutas en `index.html`:
   ```html
   <img src="images/foto-real.jpg" alt="Descripción">
   ```

### Agregar Video
Para incluir el video explicativo:

1. Grabar/editar el video (formato MP4 recomendado)
2. Guardar como `video-mi-casa-soluciones.mp4` en la raíz del sitio
3. El placeholder se reemplazará automáticamente al cargar el video

### Modificar Textos
Todos los textos están en `index.html`. Buscar y reemplazar según necesidades.

### Cambiar Colores
En `styles.css`, modificar las variables CSS:
```css
:root {
    --color-ambar: #FFB000;
    --color-carbon: #393536;
    /* etc... */
}
```

## Optimización SEO
